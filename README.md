# smart-docs-ai

Smart Docs Ai — website
Static single-page site for Smart Docs Ai, served by GitHub Pages from `main` via `.github/workflows/pages.yml`.

- Third brand under common ownership with Mentis Veritas and Noodle Mind Ai; mirrors the Noodle repository setup.
- No custom domain yet. Add a `CNAME` file when the domain is bought.
- Brand name: Smart Docs Ai (capital A, lowercase i; always three words).
- Doxie, the Smart Docs Ai visual agent, comes from Jarvis: Jarvis Mee Agents is the control copy. `mee/doxie.js` and `mee/SOURCE.json` are published from Jarvis by `tools/mee_publish.py` (Jarvis PROCEDURES P89 item 12). Do not edit anything in `mee/` here; `.github/workflows/mee-check.yml` fails if the copy no longer matches what Jarvis published.
